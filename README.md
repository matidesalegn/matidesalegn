## 🚀 About Me

**Senior Data Engineer & AI/ML Engineer** at **[Kifiya Financial Technology PLC](https://kifiya.com)** in Addis Ababa, Ethiopia 🇪🇹

*5+ years building with data and software (since 2021), including production data engineering at scale since 2024.*

I architect and operate **production data platforms** for financial technology serving **African markets** - the full data lifecycle, from real-time CDC ingestion and lakehouse modeling to governed, BI-ready serving for **multiple institutional partners**.

<img align="right" alt="Data Engineering" width="320" src="https://raw.githubusercontent.com/abhisheknaiidu/abhisheknaiidu/master/code.gif"/>

- 🔭 **Currently working on:** Apache Iceberg medallion lakehouse, real-time CDC (Debezium/OLake), ClickHouse OLAP, lakehouse governance (OpenLineage, OpenMetadata, Ranger)
- 🌱 **Currently learning:** Apache Flink stream processing, Snowflake
- 🤖 **AI/ML Focus:** LLM orchestration with LangChain, LangGraph, CrewAI & RAG systems; Feast feature store
- 🔬 **Research:** Amharic SLM quantization (paper in progress, EMNLP 2026 MRL target); Ethiopian-language RAG & OCR
- 🌍 **Specialization:** Multilingual AI for Ethiopian languages (Amharic, Afan Oromo)
- 💼 **Open to:** Senior Data Engineer, Data Platform & AI/ML opportunities
- 💬 **Ask me about:** Iceberg, Trino, CDC, ClickHouse, AWS data services, or LLM deployment
