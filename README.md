## Start with CDC Starter

[CDC Starter](https://github.com/matidesalegn/cdc-starter) is the change data capture pattern I use, small enough to read in one sitting: PostgreSQL, Debezium, Redpanda, ClickHouse and dbt in one command, with deletes, ordering by log position, heartbeat lag, and 4 checks that the warehouse matches the source.

Two larger builds of the same pattern:

- [World Bank CDC analytics](https://github.com/matidesalegn/wb-cdc-analytics): a three-day take-home assessment, with Airflow, Prometheus and Grafana, and a written design report.
- [Kiva loan CDC analytics](https://github.com/matidesalegn/kiva-microfinance-loan-cdc-analytics): a take-home assessment, extended since, with Dagster and a reconciliation monitor that alerts by email.

My production work lives in private employer repositories; the [CV](https://matidata.ethioneural.com/cv) covers it.
